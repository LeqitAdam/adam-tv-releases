# adam-tv Releases

Fertige Android-TV-APKs von **adam-tv**. Die App prüft hier auf Updates (`releases/latest`) und installiert sie selbst.

- Installieren: APK aus dem neuesten Release auf die Box (USB, Web-Installer der Box oder `adb install -r`).
- Updates: in der App unter Einstellungen → „Nach Updates suchen“.

Der Quellcode liegt in einem privaten Repository; dieses hier enthält nur Builds.
